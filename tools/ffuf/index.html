How to use

Choose a profile, enter your target and wordlist, then copy to Bash or Zsh. FFUF replaces FUZZ with each word. Local ffufrc settings still apply.

Directory fuzzing

ffuf -u 'https://example.com/FUZZ' -w 'common.txt'

Parameter name fuzzing

ffuf -u 'https://example.com/?FUZZ=test' -w 'burp-parameter-names.txt'

Parameter value fuzzing

ffuf -u 'https://example.com/?id=FUZZ' -w 'values.txt'

Replace id with your parameter and values.txt with your own value wordlist.

Header and virtual host fuzzing

ffuf -u 'https://example.com/' -w 'hosts.txt' -H 'Host: FUZZ.example.com'

Use a header such as X-Test: FUZZ for other HTTP header inputs. A Host header changes HTTP routing, not TLS SNI.

Raw HTTP request file

ffuf -request 'req.txt' -w 'wordlist.txt'

Add -request-proto 'http' for plain HTTP. The request file must contain FUZZ; pasted text is only a preview.

Common filtering options

Matchers select responses; filters remove unwanted matches. Use -mc 'all' to consider every status, -fc '404' to hide missing pages, and -fs, -fw or -fl to exclude measured byte sizes, word counts or line counts. Use -fr 'not found' for a response pattern. Measure your target's responses before choosing numeric filters.

FFUF uses Go regular expressions. The generator checks common syntax errors, but does not implement the complete Go regex engine.

Wordlist presets and maintenance

The local preset list is version 3, maintained in assets/js/ffuf-generator.js as WORDLISTS. To update it, verify filenames against SecLists and the environment, edit that list, increment its version and rerun the generator tests. No automatic synchronization occurs.

Current SecLists names the medium directory list DirBuster-2007_directory-list-2.3-medium.txt. Older installations may use directory-list-2.3-medium.txt. rockyou.txt may need decompression from rockyou.txt.gz.
